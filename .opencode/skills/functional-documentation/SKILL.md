# Functional Documentation

Use this skill when producing technical-functional documentation for developers, admins, or operators.

## Objectives

- Keep docs accurate, concise, and operational.
- Align all statements to real implemented behavior.

## Workflow

1. Identify the target audience and document purpose.
2. Extract behavior from current code/config.
3. Write step-based instructions with prerequisites.
4. Add troubleshooting and verification notes.
5. Avoid promises for non-implemented features.

## Documentation standards

- Prefer short sections with action-oriented titles.
- Include concrete commands/paths where relevant.
- Call out permission and environment assumptions.

## Deliverables

- Updated document sections with practical guidance.
- Consistency check against current implementation.
